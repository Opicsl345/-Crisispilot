# 🚨 CrisisPilot

**CrisisPilot** bridges the gap between chaotic civilian emergency reports and rapid, data-driven government response. It transforms unstructured distress calls into structured triage data, maps them instantly, and automatically dispatches autonomous drone surveillance to stream live aerial footage.

## ✨ Key Features
* **Civilian Reporting Portal**: Allows users to quickly log disasters with descriptions and exact geolocations.
* **Smart Backend Triage**: A FastAPI-powered backend that processes and prioritizes incoming emergency feeds.
* **Government Command Center (`authority.html`)**: An interactive GIS dashboard built with Leaflet Maps for live incident tracking and status updates.
* **Autonomous Drone Dispatch**: Instantly triggers flight paths, calculates telemetry distance, and launches aerial surveillance streams.
* **Edge AI Vision Integration**: Processes overhead video streams to track and count crowds reliably.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript, Leaflet.js
* **Backend**: FastAPI, Python, OpenCV, Flask
* **AI/Video**: Edge AI tracking logic & Lamina Labs presentation walkthrough
